# Налаштування Vapi вручну (пілот)

Формат tool-calls / `toolCallList[].parameters`, `results[].toolCallId` і `artifact.transcript` звірено з [Vapi Server events](https://docs.vapi.ai/server-url/events). Для server auth Vapi описує `credentialId` та заголовок `X-Vapi-Secret` для звичайного token credential ([Server authentication](https://docs.vapi.ai/server-url/server-authentication)). Версії payload можуть змінюватися; перевірте schema на момент налаштування.

1. Створіть Assistant у Vapi Dashboard і перенесіть налаштування з `assistant.template.json`. Плейсхолдери моделі, голосу й транскрайбера замініть тільки після перевірки підтримки української в документації провайдерів.
2. Створіть Function tool із параметрами `tools/submit_booking_request.json`, увімкніть server URL та замініть `{{SERVER_URL}}` і `{{VAPI_CREDENTIAL_ID}}`. Створіть Vapi Custom Credential зі значенням `{{VAPI_SECRET}}`; для звичайного token credential документація описує `X-Vapi-Secret`. Перевірте фактичний заголовок для обраного виду credential у docs.vapi.ai.
3. Додайте штатний `endCall` tool, якщо його підтримує обрана конфігурація Assistant. Звірте актуальний формат `model.tools` з docs.vapi.ai.
4. Укажіть серверний webhook `https://<ваш-публічний-хост>/vapi/webhook`, `serverMessages` з шаблону, запис розмов і обмеження тривалості. Вибір і підтримку конкретних полів звірте з docs.vapi.ai.
5. Для локального тесту можна тимчасово відкрити локальний сервер через тунель. Тунель робить тестовий endpoint публічним: використовуйте лише вигадані дані, довгий тимчасовий секрет, не надсилайте реальні записи, зупиніть тунель і відкличте секрет одразу після тесту.
6. Виконайте лише тестовий web-call з вигаданим пацієнтом на кшталт «Тестовий Пацієнт», номером `+380000000000` і вигаданою скаргою. Перевірте у локальному логові лише id та коди/результати; не записуйте ПІБ, телефон, скаргу чи секрет.
7. Перевірте, що заявка збережена в локальній тестовій базі, дубль tool-call не створив дублікат, екстрений випадок отримав термінову мітку, Telegram помилка не зламала відповідь інструмента.

Не перевірені у цьому репозиторії: назва header-а credential для вашого типу інструмента, поля config для вибраних провайдерів, повна сумісність моделей з українською і записи у вашому Vapi workspace. Звірити з docs.vapi.ai.

# Робочі правила

Призначення: демонстраційний бекенд голосового асистента клініки на FastAPI, PostgreSQL і Retell AI. Команди: `uvicorn app.main:app --reload` або `docker compose up --build`; міграції застосовуються автоматично. Залежності: `python -m pip install -r requirements.txt`. Конфігурація — локальний `.env`, який не комітити. Не записувати реальні дані пацієнтів або секрети у код, логи, документацію чи Git. Не підключати клінічних пацієнтів до оформлення договорів, згоди, захищеного хостингу та політик зберігання/доступу. Не змінювати клінічні правила `prompts/olena_system_prompt.md` без окремої вимоги.

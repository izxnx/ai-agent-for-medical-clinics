# Робочі правила

Призначення: бекенд голосового асистента клініки на FastAPI, PostgreSQL та Vapi. Локальний запуск: `uvicorn app.main:app --reload`; Docker Compose: `docker compose up --build`. Змінні розміщуються у локальному `.env` (не комітити). Не записувати реальні дані або секрети в код, логи, документацію чи Git. Не використовувати систему з пацієнтами, доки немає необхідних договорів, погодженої згоди/повідомлень, захищеного production-хостингу та затверджених політик. Не змінювати клінічні правила `prompts/olena_system_prompt.md` без окремої вимоги.
